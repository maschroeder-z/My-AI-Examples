# AI Solutions – Video Examples

This repository contains practical examples, source code, AI Skills, configuration files, and supporting resources demonstrated in my YouTube videos about AI solutions, Microsoft Copilot Studio, Microsoft 365 Copilot, agents, automation, and related technologies.

The repository is designed as a growing collection. Each video and its associated examples are stored in a dedicated directory.

## Repository structure

Every example directory contains its own `README.md` with information about the corresponding video, demonstrated features, prerequisites, directory contents, and instructions for using the examples.

```text
.
├── README.md
├── New-Copilot-And-Skills/
│   ├── README.md
│   └── ...
├── Another-Video-Example/
│   ├── README.md
│   └── ...
└── ...
```

The root `README.md` provides the repository overview and example index. Detailed technical information belongs in the README inside each example directory.

## How to use this repository

1. Find the directory that corresponds to the video you are watching.
2. Open the directory's `README.md`.
3. Review its prerequisites and example-specific instructions.
4. Inspect the supplied scripts and configuration files.
5. Install only the dependencies required by that example.
6. Test the example in a development or non-production environment.

## What an example directory can contain

Depending on the video, an example directory may include:

- Skill definitions and `SKILL.md` files
- Python, JavaScript/Node.js, Go, Bash, or Shell scripts
- Source code and configuration files
- Templates and reference documents
- Sample input and output files
- Images or other supporting assets
- Example-specific installation and usage instructions

Not every directory uses the same technology or structure. The dedicated README is therefore the primary source of information for each example.

## Important notes

- The examples are provided for demonstration and educational purposes.
- Product features, preview status, licensing requirements, and user interfaces can change over time.
- Review scripts, dependencies, and configuration files before using them.
- Never commit passwords, client secrets, access tokens, certificates, or other credentials.
- Apply your organization's security, compliance, data-protection, and governance requirements.
- Test examples carefully before using them with production systems or business data.

## Feedback and contributions

Suggestions, corrections, and improvements are welcome. Use the repository's issue functionality to report a problem or propose an enhancement. If pull requests are enabled, keep changes focused and identify the affected example directory.

When adding examples for a new video:

1. Create a dedicated directory with a clear and descriptive name.
2. Add a `README.md` to that directory.
3. Keep all files associated with the video inside the directory.
4. Add the new directory to the **Available examples** table in this root README.
